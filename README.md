# Goblin Counter 🧟‍♂️

Een elegante **Magic: The Gathering goblin counter** webapp gebouwd met React, Framer Motion en Tailwind CSS.

## ✨ Features

- 📊 Track tapped en untapped goblins
- 🎨 Mooie animaties met Framer Motion
- 🎭 Thematisch design met goblin-thema
- ♻️ Reset-functie
- 📱 Responsive design

## 🚀 Hoe te gebruiken

1. Clone de repository
2. Installeer dependencies: `npm install`
3. Start de development server: `npm run dev`
4. Open je browser op `http://localhost:5173`

## 📦 Dependencies

- React
- Framer Motion
- Lucide React (voor iconen)
- Tailwind CSS

## 🎮 Functies

- **Tap/Untap Goblins** - Beheer je goblin army
- **Plus/Minus knoppen** - Manueel toevoegen of verwijderen
- **Total Counter** - Zie het totaal aantal goblins
- **Reset** - Start opnieuw
